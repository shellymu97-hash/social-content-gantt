# גאנט תוכן סושיאל

כלי לתכנון תוכן חודשי לאינסטגרם ופייסבוק — לוח שנה עם משבצות תוכן, חגים ישראליים,
וסנכרון בין מחשב לנייד.

## מה יש כאן

| נתיב | מה זה |
|---|---|
| `index.html` | **הדף שמתפרסם.** קובץ אחד עצמאי — פונטים, קוד וסגנון בפנים. זה מה ש-GitHub Pages מגיש. |
| `template.html` | הקוד לעריכה. `__FONT_R__`, `__FONT_B__` ו-`__SYNC__` מוחלפים בבנייה. |
| `build.py` | בונה את כל הגרסאות מהתבנית. |
| `*.sub.woff2` | הפונט Talent_FS מצומצם לעברית ולטינית (64KB במקום 140KB). |
| `תכנון-תוכן-סושיאל.html` | עותק מקומי לשמירה במחשב, עם הפונט המלא. |

## פרסום

הדף כבר בנוי. GitHub Pages מגיש את `index.html` מהשורש כמו שהוא — אין שלב בנייה בענן.

```bash
git push
```

## עריכה

עורכים את `template.html` ואז:

```bash
python3 build.py
```

## סנכרון

הנתונים נשמרים ב-Supabase תחת מפתח אקראי באורך 43 תווים שנוצר בדפדפן.
הטבלה `content_plans` חסומה לגישה ישירה; הכל עובר בשתי פונקציות `security definer`
שדורשות את המפתח: `plan_pull` ו-`plan_push`.

המפתח נשמר ב-`localStorage` ומועבר בין מכשירים דרך ה-fragment של הקישור (`#k=…`),
שלא נשלח לשרת. **מי שמחזיק בקישור יכול לקרוא ולערוך את התוכן** — לא לפרסם אותו.

בלי סנכרון פעיל הכל עובד מקומית מול `localStorage` בלבד.

## הערה על הפונט

קובצי המקור של Talent_FS לא נכללים כאן — הם מסחריים. הקובץ הבנוי מטמיע
תת-קבוצה שלהם (עברית ולטינית בלבד) כמו כל webfont. הבנייה דורשת את
`reg.sub.woff2` ו-`bold.sub.woff2` שכן נמצאים בריפו.
